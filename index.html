Test Plan

How I Approach Testing

Scope, test types, known risks, and entry/exit criteria for both products.

🏆
Challengers iOS — CHG-TP-002 v2.0
iOS 17+ · SwiftUI · Firebase · Cloudinary · 32 cases
  • Smoke P0 · 3 cases
    Launch, sign-in, create challenge, toggle completion. Failure here blocks the session.
  • Happy Path P1 · 11 cases
    Auth flows, challenge lifecycle, check-in photo, QR invite, ranking, notifications.
  • Edge / Negative P1–P2 · 16 cases
    Offline mode, midnight cache, upload race condition, account linking, GDPR deletion.
  • Regression
    Full suite re-run after each fix. Smoke subset only when the fix is isolated.
  • Exploratory 30 min · unscripted
    Deep-link entry, mid-session locale switch, Firestore offline persistence.
🌐
jay-portfolio.dev — JPF-TC-001 v1.0
React · TypeScript · Tailwind · Playwright · 28 cases
  • Smoke 3 cases
    Root loads clean; LandingHero renders; CTA dismisses hero to IOSHome.
  • Navigation 6 cases
    Detail routing, back button (skipLanding flag), hard-refresh on deep link.
  • Content 5 cases
    ABOUT / EDUCATION accuracy; all 3 projects listed; tech stack rows; hero images.
  • Links 7 cases
    App Store (3), GitHub (2), LinkedIn, Resume PDF — correctness via window.open intercept.
  • Visual 4 cases
    Gradient persistence, entrance animation, iOS-style separators/chevrons, 375px layout.
  • Edge / Negative 3 cases
    Invalid route IDs → NotFound; cold deep-link entry. Both FAIL cases found here.
⚠️
Risks & Mitigations
Challengers — identified from source code
  • FCM auth error ~weekly
    Run notification tests right after a fresh Firebase Function deploy.
  • AASA Team ID missing
    Verify before session; CH-QR-001 is blocked if AASA not live.
  • dateKey listener stale past midnight
    CH-CHAL-006 targets this; run near midnight or manipulate device clock.
  • Silent upload failure push disabled
    Check via Xcode console; CH-CHKIN-003 logs this as P2.
  • Single physical device
    Friend/QR 2-device tests partially covered with Simulator — no camera, no FCM.
📋
Entry / Exit Criteria
CHG-TP-002 §7–8
  • Entry
    Build installs; Firebase + FCM live; AASA deployed; both accounts ready; Firestore seeded.
  • Exit — Smoke P0
    All 3 smoke cases pass. Any failure blocks release.
  • Exit — P1
    All happy-path and critical edge cases pass; no open Critical bugs.
  • Exit — Regression
    Full 32-case suite run once on the release candidate build.
  • Severity scale
    Critical → High → Medium → Low · IDs: CH-{TYPE}-{###}

Outcomes

Challengers (manual): 24/32 cases passed on first run. 6 required a fix and retest — all resolved. 2 were blocked due to AASA not being deployed, so 30 cases were executed in full. Found 6 bugs across the session. The high-risk cases — midnight cache (CH-CHAL-006), upload race condition (CH-CHKIN-002), Apple Sign-In linking (CH-AUTH-004) — all came back clean.

jay-portfolio.dev (Playwright): 26/28 cases passed. The 2 failures both came from edge.spec.ts — invalid routes were rendering LandingHero instead of a 404 page. Root cause: handleScrollDown() was calling window.location.href directly instead of React Router's navigate(). Both bugs were filed and resolved.
